Política de privacidad de Wabid

Última actualización: 5 de octubre de 2026

Qué es Wabid

Wabid es un asistente personal de uso privado de David Salguedo (Lima, Perú). No está abierto al público: el registro de cuentas nuevas está cerrado y solo su titular puede iniciar sesión.

Qué datos usa

  • Cuenta: el correo y nombre de la cuenta de Google con la que inicias sesión.
  • Finanzas: cuentas, movimientos, presupuestos y pagos que registras.
  • Google Calendar (permiso calendar.events): leer tus eventos para mostrarte la agenda y crear o mover eventos solo cuando tú lo pides. Wabid no invita a otras personas.
  • Gmail (permisos gmail.readonly y gmail.compose): leer remitente, asunto y un extracto de tus correos para mostrarlos y resumirlos, y crear borradores de respuesta. Un correo solo se envía cuando tú lo confirmas en la pantalla de Wabid.
  • Notas y tareas: el contenido de tu repositorio privado de notas en GitHub, para buscar y gestionar tareas.

Uso limitado de los datos de Google

El uso que hace Wabid de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. Esos datos solo se usan para darte las funciones de Wabid que tú pides; no se venden, no se usan para publicidad y no se usan para entrenar modelos de inteligencia artificial generales.

Solo se transfieren a terceros cuando hace falta para ejecutar la función que pides: el texto necesario se envía a un proveedor de modelos de lenguaje (OpenRouter, que lo enruta a DeepInfra) para redactar la respuesta, y a ElevenLabs para convertirla en voz. Esos proveedores procesan el texto solo para devolver el resultado.

Ninguna persona lee tus datos de Google, salvo que tú lo autorices expresamente, que sea necesario por seguridad o para investigar un abuso, o que lo exija la ley.

Dónde se guardan

En una base de datos privada (Supabase, región Estados Unidos oeste) con acceso restringido a tu usuario. Los tokens de acceso a Google se guardan cifrados. Los proveedores de modelo de lenguaje y de voz descritos arriba reciben solo el texto de cada pedido.

Cómo revocar el acceso o borrar tus datos

  • Desde Wabid: Agenda → Desconectar Google.
  • Desde Google: myaccount.google.com/permissions → Wabid → Quitar acceso.
  • Para borrar todos tus datos, escribe al correo de contacto.
